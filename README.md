# 🚀 University Chat

University Chat is a real-time social communication platform designed for students, developers, and academic communities. It combines the structure of a forum with the speed of a live chat system, creating a hybrid environment similar to Reddit + Discord for educational and technical discussions.

Built with scalability in mind, the platform uses modern web technologies and a serverless backend powered by Firebase.

---

# 🧠 Vision

The goal of University Chat is to create a digital space where students can:

- Communicate in real-time
- Share knowledge and ideas
- Build academic communities
- Collaborate on projects
- Grow within a structured tech ecosystem

This project is designed as the foundation for a future AI-integrated social platform.

---

# ⚙️ Core Features (MVP)

## 🔐 Authentication System
- Email and password registration
- Secure login system
- User session management

## 💬 Real-Time Chat
- Global chat room for all users
- Instant message delivery
- Live updates without page refresh
- User identification via UID/email

## 🗄️ Persistent Data Storage
- All messages stored in Firestore database
- Real-time synchronization across users
- Data persistence across sessions

## 👤 User System
- Unique user accounts
- Authenticated interactions
- Scalable structure for future profiles
